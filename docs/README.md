# 易开面板

易开面板是面向 Windows 的本地 PHP 开发环境，目标是让不熟悉服务器配置的用户快速运行多个本地网站。

- 产品名：**易开面板**
- 英文名：**Yikai Panel**（对外名称）
- 产品定位：简单好用的 Windows 本地 PHP 开发环境
- 当前开发版本：0.7.4（0.7.0 安装包仍为已发布版本）
- 默认根目录：`D:\yikai`
- 官网：<https://panel.yikai.cn>

## 当前实现概览

已可用：

- C# / WinForms Windows x64 面板，支持系统托盘。
- 多项目列表、搜索、星标、右键菜单、项目独立启停。
- Nginx 或 Apache 2.4.39（二选一）、PHP 8.0 / 8.2 / 8.5、MySQL 5.7 / 8.0、SQLite。
- 默认 Nginx + PHP 8.2 + MySQL 8.0 一起启动；状态栏可单独启动、停止、重启各服务，PHP 可按版本启停，并可设置新项目默认 PHP 版本。
- `.yikai` 本地域名和 hosts 同步；项目伪静态配置。
- YikaiCMS / WordPress 站点可手动检测核心程序更新（只读，不自动升级；插件和主题仍在站点后台管理）。点击后，YikaiCMS 向其官方更新服务发送当前版本、站点域名和 PHP 版本；WordPress 向 WordPress.org 查询当前核心版本。
- 中文、英文、日文的数据库简洁页面和 Adminer。
- PHPStudy 项目扫描、批量选择、网站文件与完整数据库复制导入。
- root 密码修改与重置、后台入口识别、目录大小计算。

0.6.6 已补充：

- `panel.json` 配置 schema 版本、默认值文件和 schema 文件。
- 自动启动、关闭到托盘、默认 PHP、默认 MySQL 和 Web 服务器配置字段。

0.7.0 已补充（2026-09-17）：

- 界面品牌统一为“易开面板 / Yikai Panel”（窗口、托盘、标识、关于 / 升级、错误提示、数据库页面页脚）。
- 项目卡片显示 YikaiCMS 版本徽标，读取项目 `config/version.php` 的 `CMS_VERSION`。
- Apache 2.4.39 集成，Nginx / Apache 切换；状态栏单独启停各服务，PHP 按版本启停，新项目默认 PHP 版本。
- 配置文件编辑器：php.ini、Nginx / Apache / MySQL 自定义配置，保存前检查、备份，失败自动回滚。
- 界面：暖色配色、项目头像、新建按钮与对话框按钮重做、PHPStudy 导入移入“工具”菜单、新建项目可选择存放位置。
- 项目专属数据库账号：新建项目可指定库名、用户和密码，启动时自动建库授权。
- “配置”菜单：配置文件、SSL 证书、Web 服务器、默认 PHP / MySQL、root 密码集中在一处，“工具”只保留一次性操作。
- SSL 证书：本地根证书（用户确认后信任）、按项目自动签发或导入证书、独立 HTTPS 端口，Nginx 与 Apache 均支持。
- 窗口大小按屏幕决定并记住上次尺寸；窗口变窄时顶部按钮收成图标。
- 项目列表显示 HTTPS 徽标，项目卡片显示证书来源与有效期。
- 外观设置：浅色 / 深色 / 跟随系统主题，界面字号三档（行高与窗口最小尺寸一起缩放）。
- 项目卡片改为标签 + “标题 + 内容”两列信息，按钮区固定宽度，宽屏下不再拉散。
- PHP 扩展可视化勾选（按版本），保存时检查、备份并重启该版本 PHP，加载失败自动回滚。
- 局域网访问开关：项目网站端口可放开到 0.0.0.0，并可添加 Windows 防火墙规则；数据库页面与 MySQL 始终只在本机。

当前仍在规划：

- 顶部将“全部启动 / 全部停止”合并为状态按钮。
- 服务状态详情（版本、PID、受影响项目数量）的独立面板。
- MySQL 5.7 / 8.0 默认二选一启动，并增加项目连接切换向导。
- 全量环境包、最小环境包和正式一键安装 EXE。

## 目录约定

```text
D:\yikai\
├─ soft\       运行软件和组件
├─ wwwroot\    本地项目文件
├─ config\     面板配置及生成的 Nginx/PHP 配置
├─ data\       MySQL 5.7 / 8.0 独立数据目录
├─ backups\    面板、项目和数据库备份
├─ logs\       运行日志
├─ temp\       临时迁移、更新和进程记录
├─ src\        面板源码
└─ docs\       本开发文档目录
```
